## 추천 방향

**Finder의 회색 사이드바와 흰 작업 영역 + Nova의 직선 분할 패널 + macOS 네트워크 설정의 상태 점**을 추천해. Things는 본문 밀도와 제목 계층만 보조로 참고하면 돼.

실제 macOS는 창과 버튼에도 둥근 모서리를 사용해. 이번 방향은 macOS를 그대로 복제하는 게 아니라, 그 색감·툴바·정보 구조를 가져오고 내부 패널과 컨트롤은 직각으로 재해석하는 거야. 아래 치수와 색은 원본에서 측정한 값이 아니라 이번 프로젝트에 적용할 제안이야.

## 적용 규칙 제안

- 패널·카드·탭·입력창·버튼: `border-radius: 0`. 상태 점만 원형.
- 사이드바 약 224px, 오른쪽 출처 패널 약 280px, 툴바 높이 48px. 화면 크기에 따라 조정.
- 선택 행은 중간 회색 직사각형 + 글자 굵기 + 8px 초록 점으로 표시.
- 일반 비선택 탭은 8px 노랑 점. 빨강은 오류·사용 불가·확인 필요 등의 뜻과 충돌할 수 있어서 그 경우에 쓰는 쪽 추천.
- 상태 점 제안: 초록 `#28c840`, 노랑 `#febc2e`, 빨강 `#ff5f57`. 행 선택과 상태는 글자·배경으로도 구분.
- 색 제안: 사이드바 `#e8e8e6`, 본문 `#fafaf9`, 선 `#d2d2ce`, 본문 글자 `#262624`.
- 큰 환영 문구, 둥근 추천 카드, 프로필 알약 배지를 줄이고 문서형 제목·목록·라벨/값으로 변경.
- 기존의 왼쪽 탐색 / 중앙 상담 / 오른쪽 출처 구조는 Finder·Nova의 분할 방식과 잘 맞아.

## 수집 범위

웹의 공식 소개 화면, 공식 지원 문서, 개발사 제공 App Store 이미지를 확인했어. Mac 앱을 설치하거나 로그인해서 실제 기능을 조사한 것은 아니야. 이미지는 시각 비교를 위한 참고 자료이며 원 제작자의 자산이야. 제품의 실제 학사 수치·동작은 이 보드에서 바꾸지 않았어.

`index.html`의 사이드바 예시는 방향 확인용으로 탭 선택만 바뀌어. 상담 기능을 구현한 제품 화면은 아니야. 기존 `prototype/`과 기존 목업은 수정하지 않았어.
