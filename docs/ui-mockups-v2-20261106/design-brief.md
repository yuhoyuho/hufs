## 기본 디자인 방향

- 기획서의 기존 네이비를 이어받고 밝은 배경·선명한 한국어 타이포그래피를 사용해.
- 대학 학사 상담의 신뢰성과 학생이 편하게 질문하는 느낌을 함께 표현해.
- 필수 흐름은 `프로필 → 질문 → 적용 조건 → 답변 → 출처/추가 확인`이야.
- 도구명·RAG·모델명 같은 구현 상세는 제품 화면에 넣지 않아.
- 실제 학번·실명·계정 로그인·성적표 업로드·클라우드 동기화는 화면에 추가하지 않아.
- 고정된 4년 캘린더, 졸업 가능 확정 판정, 펫·장학 추천은 본선 범위에 포함하지 않아.
- 목업의 추천 질문과 예시 프로필은 시연용이야. 공식 운영 서비스라는 표현이나 대학 공식 마크는 쓰지 않아.

## 내용 일관성

- 기본 예시: 서울캠퍼스 / 2026학번 / 서양어대학·스페인어과 / 2학기 / 신입학·재학.
- 졸업학점 답변의 예시는 이중전공 이수 유형을 적용한 126학점: 전공42·이중전공42·교양32·기초6.
- 서울2024학번의 비사범대·비AI융합대 이중전공 예시는 총134학점. 영역별 최소학점의 합과 총 졸업학점은 별개이므로 134를 54+42+32의 합으로 표현하지 않아.
- 일반 학사정보의 25학번 이후32학점과 2026-2공고의34학점은 충돌 상태로 제시해. 한쪽을 정답이라고 표시하지 않아.
- 가정 질문은 ‘이번 답변에만 적용’으로 표시하고 저장 프로필을 변경했다고 표현하지 않아.
- 프로필은 이 기기 브라우저에 저장되고 질문과 필요한 프로필 항목은 답변 생성에 사용돼. 학번·실명 미수집 안내는 짧고 정확하게 써.

## 제작 방식

실제 서비스·공식 제품 소개·디자인 갤러리를 ego-browser로 조사하고, 확인한 화면의 구성 원리를 참고해 새 UI를 생성해. 기존 제품의 로고나 고유 화면을 복제하지 않아. 이미지 제작은 기본 제공 `image_gen`을 사용하고, 최종 프롬프트와 레퍼런스는 함께 보관해.
