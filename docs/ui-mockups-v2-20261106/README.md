# 외대 놓침방지 · 화면별 UI 목업

`index.html`을 브라우저에서 열면 11개 시안과 레퍼런스를 한 번에 볼 수 있어. 각 이미지를 누르면 PNG 원본이 열려.

- 기본 웹 화면 7장: 온보딩, 홈, 개인화 답변, 자료 충돌, 추가 질문·가정 조건, 프로필 관리, 프로필별 답변 비교
- 모바일 화면 2장: 홈, 개인화 답변
- 홈 스타일 대안 2장: 웜, 다크
- `overview.png`: 전체 시안을 모아 보는 보드
- `references/README.md`: 조사한 24곳의 링크, 참고한 구성, 캡처 한계
- `references/`: 레퍼런스 캡처 24장과 보드 3장
- `prompts-complete.json`: 실제 사용한 11개 생성 프롬프트
- `design-brief.md`: 기획서 반영 기준과 화면별 역할
- `assets.json`: 최종 이미지별 실제 해상도

제작 기준은 `../proposal.pdf` 10쪽 중 서비스 정의·화면 구성·시연 시나리오야. 기존 `../mockups/`는 교체하지 않았어.

기본 시안은 네이비·화이트·연한 청록을 사용했어. 홈의 저장 프로필과 답변의 적용 조건을 연결하고, 규정 충돌은 차분한 황색, 이번 질문에만 적용하는 가정 조건은 보라색으로 구분했어.

이미지는 기본 제공 **image_gen**으로 제작했어. 기본 홈 시안을 먼저 생성하고 이를 디자인 참고 이미지로 사용해 나머지 화면을 이어 만들었어. 원본 PNG는 이 폴더에 모두 복사되어 있으므로 별도 생성 이미지 폴더에 의존하지 않아.

이 결과물은 시각 목업이야. 갤러리는 PNG를 열어 보는 용도이며 챗봇·프로필 저장 기능을 구현한 웹앱은 아니야. 구현할 때 사용할 실제 글꼴·아이콘·간격은 공통 컴포넌트로 정리하면 돼. 학사 답변 수치는 기획서의 시연 조건을 표현한 예시야.

기본 웹 시안은 약 1586×992, 모바일은 864×1821, 웜·다크 대안은 1717×916이야. 모델이 반환한 실제 크기를 그대로 보존했고 해상도를 부풀리지 않았어.
