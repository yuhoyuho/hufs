# 외대 놓침방지 · 클릭 프로토타입

기획서(`../docs/proposal.md`)의 핵심 흐름을 눌러 볼 수 있게 만든 프로토타입이다.
AI·서버는 연결하지 않았고, 질문 해석은 키워드 규칙으로 대신한다. 수치와 자격은 `src/data/rules.ts`의 규정 데이터로 계산한다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 시연 시나리오 테스트 (Vitest)
npm run build    # 정적 빌드 → dist/
```

## 구성

| 파일 | 역할 |
|---|---|
| `src/data/rules.ts` | 졸업학점 배분표(서울 2015~2024 / 2025 이후), 이중전공 공고, 우선배정 충돌, 출처·확인일 |
| `src/engine/answer.ts` | 질문 → 주제 판별 → 조건 확인(추가 질문·가정 조건) → 규정 대조 → 답변 객체 |
| `src/engine/answer.test.ts` | 기획서 시연 시나리오 8개와 예외 케이스 |
| `src/components/ProfileForm.tsx` | 프로필 등록·수정·삭제 |
| `src/components/ReplyCard.tsx` | 적용 조건, 답변, 자료 충돌, 추가 질문, 근거 표시 |
| `src/App.tsx` | 화면 전환, 브라우저 저장, 채팅, 프로필 비교 |

## 데이터 기준

한국외대 홈페이지 학사정보·학사공지 2026.11.06 확인 기준이다(졸업이수학점, 이중전공, 휴·복학, 2026-2학기 이중전공 신청 공고).
수록 범위는 서울캠퍼스 비사범대 배분표이고, 사범대학·글로벌캠퍼스·2014학번 이전은 "지원하지 않는 조건"으로 안내한다.
